## Binary Sorter Visualisation
<img width="900" height="925" alt="sorter" src="https://github.com/user-attachments/assets/3b4594d0-dd4c-4115-8494-7c5f869f7e24" /> <br>
This program is a sorting algorithm visualizer built with SFML. It generates a set of random bars and visually demonstrates how different sorting algorithms (Bubble Sort and Quick Sort) organize the data. The application highlights comparisons and swaps in real time while tracking the number of operations performed.
### Controls:
* `Space` – Start the selected sorting algorithm.
* `N` – Switch between Bubble Sort and Quick Sort.
* `R` – Generate a new random dataset and reset the visualization.

Once sorting is complete, a **"Done!"** message is displayed on the screen.

### Project Files:
All source files, assets, and project-related files are located within the `Sorter` folder.
